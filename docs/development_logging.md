# 开发日志与最近交互排查

更新时间：2026-09-18

这是开发排查机制，不是新增聊天工具，也不是聊天或成长日志导出功能。程序正常启动后自动保存关键开发事件；关闭终端窗口不会删除已经写出的事件，但不能恢复启用前已丢失的控制台内容。

## 保存与开关

桌面入口 `frontend/pet_app.py` 启动时默认开启最小开发日志，保存到 `logs/development/run-时间-随机编号/`：

- `events.jsonl`：结构化证据，每个事件独立写入并 flush。
- `runtime.log`：同一批脱敏事件的可读版，不是完整 stdout 或 stderr 的镜像。
- 超过单文件约 8 MiB 后使用编号分段；专用目录的受管日志文件预算约 50 MiB。只删除带本机制标记、名称和路径均核验过的旧日志文件，不清理旧诊断目录、用户数据或其他文件。并发程序与当前分段可能使预算短时超出；轮转不是永久归档。

控制台原输出保留。`roxy.bat --no-development-log` 仅关闭本次启动的最小日志，不修改私人设置。模块默认 logger 是关闭的，导入不会创建目录。当前 Local Web 没有新增自动开启入口，仍可在获准的 runtime 中注入 logger。

现有 `interaction diagnostics` 是独立的详细诊断机制，其开关仍有效；关闭它不会关闭默认的最小开发日志，最小日志也不会偷偷打开详细诊断或修改用户配置。

## 关联与来源

每次运行有 run ID，每条提交有独立 trace ID。聊天历史原有消息 ID、session ID 和 ToolResult 调用 ID 不改变；开启日志时，只给本次新保存消息的 metadata 增加 run/trace ID，不迁移旧数据。相同文字重复提交不共用编号。

后台线程携带原 trace，切换会话后不把旧回复显示或保存到新会话。语义选择、参数校验、引用快照、待确认状态、工具开始和结果、真实后置条件、回复保护及最终显示分别留证。工具的执行结果与服务收尾的结果投影是不同事件，不把两条日志算成两次执行。

成长面板写按钮、记忆管理按钮及启动补昨日复盘各有独立 trace/source。按钮保存成功不证明此前聊天请求执行成功；取消、无变化、已有日志、空日和失败保持不同状态。静默后台补齐仍不调用模型。

## 隐私与失败边界

只原样保存核验过的能力／工具名、固定状态和原因码、程序生成 ID、日期、计数及布尔值。正文、标题、候选内容、原始参数、整份 ToolResult.data、系统提示、密钥、私人路径及任意未知字符串不原样保存；必要时仅保存类型、长度和哈希。原始与最终模型回复只留指纹和保护原因，不保存全文，因此最小日志不能还原模型原话。

异常只记录可信类型及核验过的项目源码文件名／行号，不保存异常消息或堆栈中的私人路径。写日志失败只给一次固定控制台告警，不改变业务执行结果。flush 不等于断电持久化保证；中途损坏的旧尾行保留，新事件换分段，排查脚本明确报证据缺口。

## 只读排查

从项目根运行：

```powershell
.\.venv\Scripts\python.exe -B scripts\inspect_recent_interactions.py --sessions 3
```

默认读取最近三个已保存会话和开发事件，不调用模型、不构造数据管理器、不写入输入文件，不展示聊天正文。可用 `--since 2026-09-18`、`--session-id 程序会话编号` 缩小范围，`--json` 输出结构化报告。

旧历史仍存在但新会话没有落盘时，近期日志不会因此消失：会话外的仅日志证据与独立按钮／后台操作合计有界保留，默认最多 36 组，始终不计入旧聊天成功。显式会话筛选严格限制范围，运行级事件单独列出。

任务确实需要对照语句时，显式加 `--excerpts`：仅展示每会话最近六条消息、每条最多 120 字的脱敏片段，不导出整份会话。片段仍可能涉及个人信息，不应公开上传。可选 `--data-dir data/private` 只核对日志明确指向的成长记录日期／ID；当前文件存在不能反证当时是哪轮或哪个按钮写入，不扫描整份长期记忆。

报告区分精确逐轮关联、仅日志证据、独立按钮／后台操作、不确定时间候选和证据缺口。只有 run/trace/session 对应才精确关联；旧消息没有 metadata 时，时间近、文字相同都不能当作因果证据。第一处显式失败与第一处已知回复保护改写分别显示，不把正常保护伪装成工具失败。缺日志、坏行、未显示、未收尾和日志被轮转移除都须如实保留不确定性。

后续用户正常测试后，可以直接结合这些本地证据定位同义表达波动和工具回复问题；最小日志上线本身不代表上述语义缺陷已修复，也不代替真实模型或桌面验收。最新测试结果只在 [current_status.md](current_status.md) 维护。

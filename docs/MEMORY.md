# Long-Term Memory

## 当前状态

V0.9 延续基础本地长期记忆原型：

- 保存用户昵称
- 保存用户明确要求记住的文本条目
- 支持查看和删除已保存条目
- 在模型提示上下文中提供基础记忆信息
- 使用 `memory.example.json` 作为公开示例结构
- 启动时缺少 `memory.json` 会自动创建本地默认文件

## 当前边界

- 使用本地 JSON 数据，不使用数据库
- 不自动推断或批量保存敏感信息
- 记忆提取、冲突处理、过期规则和重要度排序尚未实现
- `memory.json` 属于私有运行数据，不应提交到公开仓库
- `memory.example.json` 只能包含无隐私的示例结构

## 计划中

- 明确记忆分类、更新和遗忘规则
- 增加用户确认与可编辑能力
- 区分长期记忆、聊天历史和知识文件
- 增加敏感信息保护和导出/清理流程

# Long-Term Memory

## 当前状态

V2.2 在基础本地长期记忆与旧候选兼容结构上统一了普通聊天写入边界：

- 保存用户昵称
- 保存用户明确要求记住的文本条目
- 支持查看和删除已保存条目
- 在模型提示上下文中提供基础记忆信息
- 使用 `memory.example.json` 作为公开示例结构
- 启动时缺少 `memory.json` 会自动创建本地默认文件
- 显式且内容完整的“记住……”直接走正式记忆工具，只有成功 ToolResult 才能声明保存成功
- 普通对话中的稳定非敏感信息只提出具体保存建议，用户确认前不写 `memory.json` 或候选文件
- 隐式敏感信息不主动建议保存，也不建立 pending
- 旧候选文件、服务和 API 仅保留内部兼容；聊天、模型能力目录、桌面面板和 Local Web 页面均不提供候选操作

## 当前边界

- 使用本地 JSON 数据，不使用数据库
- 不自动把候选、计划、行动记录或复盘写入 `memory.json`
- 长期记忆、今日计划、行动记录、成长复盘、聊天历史和知识文件保持独立
- 已保留旧候选处理代码、冲突处理、审计、敏感检索过滤与重要度/相关性排序；旧候选处理代码不是当前用户入口
- `memory.json` 属于私有运行数据，不应提交到公开仓库
- `memory.example.json` 只能包含无隐私的示例结构

## 后续范围

- 继续验证记忆分类、更新、遗忘和过期规则的一致性
- 保持敏感信息保护、导出与清理流程可审计
- 不把普通对话重新改回自动磁盘候选或自动长期记忆提取

详细运行契约见 [memory_system.md](memory_system.md)；设计草案不覆盖这里的 V2.2 边界。

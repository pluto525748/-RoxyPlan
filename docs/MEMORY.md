# Long-Term Memory

## 当前状态

V1.0 在基础本地长期记忆上加入待确认候选流程：

- 保存用户昵称
- 保存用户明确要求记住的文本条目
- 支持查看和删除已保存条目
- 在模型提示上下文中提供基础记忆信息
- 使用 `memory.example.json` 作为公开示例结构
- 启动时缺少 `memory.json` 会自动创建本地默认文件
- 对强特征的稳定信息生成私有候选，不自动写入长期记忆
- 支持通过聊天命令或记忆候选面板确认、忽略候选
- 候选保存在 `data/private/memory_candidates.json`

## 当前边界

- 使用本地 JSON 数据，不使用数据库
- 不自动把候选、计划、行动记录或复盘写入 `memory.json`
- 复杂语义提取、冲突处理、过期规则和重要度排序尚未实现
- `memory.json` 属于私有运行数据，不应提交到公开仓库
- `memory.example.json` 只能包含无隐私的示例结构

## 计划中

- 明确记忆分类、更新和遗忘规则
- 增加候选编辑、冲突处理和过期规则
- 区分长期记忆、聊天历史和知识文件
- 增加敏感信息保护和导出/清理流程

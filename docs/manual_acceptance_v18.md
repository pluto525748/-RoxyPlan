# RoxyPlan V1.8 手动验收

先启动桌面端：

```powershell
.\.venv\Scripts\python.exe -u frontend\pet_app.py
```

验收前建议在成长面板确认当前计划，避免把已有同名计划误认为新结果。涉及删除的步骤使用测试数据，不要删除私人记忆。

## 1. 普通聊天与动作

依次说：

```text
什么是随机森林
我不想跳舞
跳个舞看看
```

预期：前两句不执行工具；第三句只触发一次 dance 和一条回复，不出现“我无法跳舞”。

## 2. 计划

先连续输入 20 次：

```text
今日计划
```

预期：20 次都直接读取计划，不询问确认、不调用普通聊天、不要求换一种说法。再分别验证“我的计划”“今天要做什么”“看看今天安排了什么”。

```text
下午帮我留50分钟学特征工程，放进今天要做的事里
看看我今天要做什么
特征工程学完了
我下午想学一会儿
```

预期：前三步真实新增、查询和完成；最后一句只询问学习内容/时长，不擅自创建。

继续回答：

```text
不知道，你帮我安排一下
第二个，一个小时
```

预期：系统先给 2～3 个建议；选择后保留下午，按第二个建议真实创建 60 分钟计划。

在同一会话创建“下午学线性规划40分钟”后说：

```text
刚才那个改成一小时
```

预期：原计划标题不变，真实时长更新为 60 分钟。

再新建一个聊天会话后说：

```text
刚才那个改成一小时
```

预期：要求重新说明计划，不引用旧会话对象。

## 3. 行动记录

```text
记录我早上通勤听了三个AI前沿电台
我已经理解随机森林的两个随机性来源
确认
查看记录
```

预期：明确记录直接执行；普通进展先询问，确认后只记录一次；列表能看到真实内容。

## 4. 记忆候选

```text
这点请记住：我的肠胃比较敏感
有哪些待确认记忆
确认记忆1
你还知道关于我的什么内容
```

请把 `1` 替换成界面实际候选编号。预期：明确敏感信息只进入候选；审核后才进入正式长期记忆；新会话仍可查询正式记忆。

准备两条测试候选后验证：

```text
有哪些待确认记忆
忽略第一个，第二个确认
```

预期：按刚才列表的真实顺序处理，不编造 ID，不重复确认。

## 5. 多动作

先创建“今晚学习机器学习”计划，再说：

```text
把今晚学习计划改成40分钟，再记录今天完成了V1.7接入
```

预期：计划时长更新，行动记录新增；回复逐项对应真实结果，不出现 `None`。

再对一个不存在的计划执行同类句子。预期：计划更新失败，但独立行动记录继续执行，整体为部分成功。

## 6. 状态与安全

```text
确认
取消
删除计划1
取消
```

预期：没有 pending 时确认/取消不执行；删除先二次确认，取消后数据不变。服务重启后旧确认必须失效。

## 7. 日志检查

控制台应能看到非敏感诊断：`[Interaction]`、`[Semantic]`、`[Planner]`、`[Tool]`。本地配置开启 `interaction_diagnostics_enabled` 后还会出现 `[Diagnostic]`；导出只含正文长度与哈希。日志不应出现 API Key、reasoning_content、完整健康记忆或本地私人路径。

## 回滚

出现回归时可在本地设置中逐项关闭：

```json
{
  "interaction_coordinator_enabled": false,
  "unified_semantic_parser_enabled": false,
  "business_resolver_enabled": false,
  "deterministic_response_enabled": false,
  "action_batch_enabled": false,
  "plan_postcondition_enabled": false
}
```

这些开关不迁移、不删除也不重写现有 JSON 数据。

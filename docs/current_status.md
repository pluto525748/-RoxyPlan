# RoxyPlan 当前项目状态

更新时间：2026-07-15

## 一句话结论

RoxyPlan 当前是一个 **V0.9 桌面成长伙伴原型**：桌宠、聊天、本地记忆、人格规则、设置面板、轻量知识读取、成长闭环、多帧 dance 和基础测试都已经跑通。

但它还不是完整的 V1 产品。当前重点仍是验证桌宠陪伴、轻量聊天、记忆可控性和本地知识增强是否成立。

## 当前完成度

### 已经落地

- PySide6 桌宠窗口：支持透明背景、常驻桌面、拖动、缩放、置顶和右键菜单。
- 桌宠图片资源：默认使用 `assets/pet/roxy_pet_transparent.png`，同时保留代码绘制的默认头像。
- 轻量动作系统：已有待机呼吸、点击跳动、气泡点头、思考摇动、学习提醒缩放、睡眠和唤醒。
- 聊天窗口：支持文本输入、回车发送、消息时间戳、自动滚动和基础样式。
- 异步模型回复：普通聊天会通过 QThread / Worker 调用模型，避免卡住 Qt 主线程。
- 本地长期记忆：支持保存昵称、`记住：...`、`我的记忆`、`忘记：...`，并把记忆加入模型提示上下文。
- 示例记忆文件：`memory.example.json` 用于公开仓库，缺少本地 `memory.json` 时会自动创建。
- 人格规则：`data/roxy_personality.json` 提供名称、性格、说话风格和简单规则回复。
- 本地提示语：`data/pet_tips.json` 当前包含 88 条气泡提示。
- 设置面板：可调整测试模式、学习提醒、睡眠时间、自动提示、缩放、置顶、桌宠图片路径和模型名称。
- 本地知识读取：`data/knowledge/` 支持 `.txt` / `.md` 文件读取，聊天时用轻量关键词匹配相关片段加入 prompt。
- 知识库入口：设置面板可打开知识库文件夹，聊天里可用 `查看知识` 查看已加载文件名。
- 舞蹈播放框架：支持读取 `assets/pet/dance/dance_*.png`，当前包含 8 帧透明测试素材和预览 GIF。
- 成长闭环：支持今日计划、行动记录、规则复盘和按日期保存成长日志。
- 成长面板：支持添加、完成、删除计划，记录行动，生成并保存复盘。
- 私有成长数据：`GrowthManager` 将本地计划和复盘保存到被忽略的 `data/private/`。
- Windows 启动脚本：`roxy.bat` 可用于启动桌宠。
- 基础测试：`tests/test_memory_logic.py` 覆盖昵称、记忆生命周期、人格规则、知识读取和 LLM client 基础行为。
- 公开仓库检查：`tests/check_public_repo.py` 用于检查隐私文件、忽略规则和文档中的敏感内容。

### 原型验证中

- LLM 接入：`modules/llm_client.py` 是 OpenAI-compatible chat completions 客户端，实际效果取决于本地 `config.json` 和模型服务。
- 本地知识增强：当前是简单关键词匹配，不是向量检索，也没有来源引用 UI。
- 长期记忆：当前是本地 JSON 读写和显式命令，不包含自动记忆判断、冲突处理、重要度排序或过期规则。
- 桌宠提醒：已有学习提醒、自动提示和睡眠逻辑，但仍是原型级规则。
- 聊天记录：当前窗口能显示本次会话，但还没有数据库级历史会话管理。

### 仍未实现

- 独立后端服务。
- 数据库持久化和数据迁移。
- 完整聊天历史管理。
- 周报、月报、长期趋势和完整分类成长记录。
- 语音输入、语音播报和固定声线。
- PDF、Word、PPT 等复杂文档解析。
- 向量检索、知识块管理和可追溯引用。
- 移动端、账号系统、跨端同步。
- 完整商业化能力。

## 项目结构判断

当前代码集中在桌面端原型：

- `frontend/` 是实际主战场，包含桌宠、聊天窗口、动作控制、气泡和设置面板。
- `modules/` 包含模型调用和成长数据管理边界。
- `data/` 保存提示语、人格、桌宠配置、知识库目录和被忽略的私有成长数据。
- `assets/` 保存桌宠图片和多帧动画素材。
- `docs/` 同时包含当前说明和未来规划，需要阅读时区分“已实现”和“计划中”。
- `backend/` 当前只是预留目录，没有独立后端实现。
- `tests/` 已经有基础逻辑测试和公开仓库检查脚本。

## 与长期愿景的距离

RoxyPlan 的长期目标是“长期成长陪伴 AI 桌宠”。当前 V0.9 已经完成了这个愿景的原型底座：

- 有桌面存在感。
- 有可聊天入口。
- 有基本人格。
- 有可控记忆。
- 有本地知识读取雏形。
- 有基础提醒和状态动作。
- 有“计划 -> 行动 -> 复盘 -> 日志”的最小成长闭环。

下一步不建议继续横向加大功能范围。更适合围绕 V1.0 稳定成长数据、记忆边界、周报月报和网页端入口。

## 当前优先级建议

1. 封板 V0.9：统一文档状态，持续确认公开仓库不会提交隐私数据。
2. 收敛 V1.0：稳定成长闭环，再设计周报、月报和网页端入口。
3. 强化记忆控制：让用户更清楚 Roxy 记住了什么、如何删除、哪些内容不会自动保存。
4. 保持知识库轻量：V1 继续只支持 TXT / Markdown 原型即可，复杂解析和向量检索延后。
5. 增加测试覆盖：优先覆盖记忆命令、设置读写、知识匹配和 LLM 未配置时的降级行为。

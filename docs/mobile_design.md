# RoxyPlan 手机版设计

## 1. 设计目标

RoxyPlan 手机版的目标是让用户可以通过手机浏览器访问 Roxy，在离开电脑时继续完成轻量成长管理。

手机版不是桌宠的替代品，也不是完整桌面端复制。  
桌面端负责常驻陪伴、深度工作和资料投喂。  
手机版负责随身访问、快速记录、计划查看和知识查询。

核心目标：

- 随时和 Roxy 对话。
- 查看和调整今日计划。
- 快速记录学习、健康、项目、赚钱和心情状态。
- 查询已投喂知识库。
- 与桌面端共享长期记忆、成长记录和知识库。

核心原则：

- 手机浏览器访问优先。
- 页面轻量，加载快。
- 适合单手操作。
- 不做复杂桌宠动画。
- 不强依赖安装 App。
- 数据同步必须清楚、可控、可恢复。

## 2. 功能范围

### 2.1 聊天

手机版聊天用于随时和 Roxy 交流。

主要用途：

- 快速提问。
- 汇报今日状态。
- 口头或文字记录成长内容。
- 查询计划。
- 请求 Roxy 总结或提醒。

聊天不应只是闲聊，而应优先服务：

- 学习推进。
- 健康提醒。
- 项目复盘。
- 收入记录。
- 长期成长。

### 2.2 今日计划

今日计划用于展示用户当天最重要的行动。

内容包括：

- 今日学习任务。
- 今日项目任务。
- 健康提醒。
- 收入或赚钱相关行动。
- Roxy 建议的最小行动。

设计重点：

- 不展示过多任务。
- 优先展示 1 到 3 个关键事项。
- 支持完成、推迟、跳过。
- 支持从聊天中生成计划。

### 2.3 成长记录

成长记录用于手机端快速记录和查看。

内容包括：

- 学习记录。
- 项目进度。
- 健身记录。
- 收入记录。
- 心情记录。

设计重点：

- 支持轻量录入。
- 支持“只记一句话”。
- 支持按日期查看。
- 支持同步到桌面端成长日志。

### 2.4 知识库查询

知识库查询用于手机端检索已投喂资料。

功能包括：

- 输入问题查询知识库。
- 查看相关资料来源。
- 查看知识块摘要。
- 打开文件详情。
- 限定项目或标签范围。

手机版初期只做查询，不建议做复杂文件管理。

## 3. 页面结构

### 3.1 首页

首页是手机端的成长总览入口。

页面模块：

- Roxy 状态区。
- 今日重点。
- 快速聊天入口。
- 今日计划摘要。
- 最近成长记录。
- 知识库快捷查询。

首页目标：

- 用户打开手机浏览器后，马上知道今天该做什么。
- 不需要翻很多页面就能进入聊天或记录。

首页推荐信息层级：

1. 今日最重要的一件事。
2. Roxy 的一句简短建议。
3. 今日计划列表。
4. 快速记录入口。
5. 知识库查询入口。

### 3.2 聊天页

聊天页用于移动端对话。

页面模块：

- 会话标题。
- 消息列表。
- 输入框。
- 发送按钮。
- 语音输入入口。
- 快捷指令。

快捷指令示例：

- 记录学习
- 记录项目
- 记录健身
- 记录收入
- 记录心情
- 查看今日计划
- 查询知识库

聊天页规则：

- 消息气泡简洁。
- 长回复折叠摘要。
- 知识库回答显示来源。
- 涉及长期记忆时必须请求确认。
- 涉及收入、健康、心情等敏感内容时谨慎保存。

### 3.3 今日计划页

今日计划页用于管理当天行动。

页面模块：

- 日期。
- 今日主线。
- 学习计划。
- 项目计划。
- 健康计划。
- 赚钱计划。
- Roxy 建议。
- 完成状态。

每个任务应支持：

- 完成。
- 推迟。
- 跳过。
- 编辑。
- 转为明日计划。
- 添加备注。

任务展示建议：

- 使用短标题。
- 显示任务类型。
- 显示预计时长。
- 显示优先级。
- 显示是否来自长期目标。

### 3.4 成长记录页

成长记录页用于按日期记录和查看成长数据。

页面模块：

- 日期选择。
- 今日总结。
- 学习记录。
- 项目进度。
- 健身记录。
- 收入记录。
- 心情记录。

每类记录支持：

- 快速添加。
- 查看最近记录。
- 编辑。
- 删除。
- 关联目标或项目。

移动端输入要尽量轻：

- 少量必填字段。
- 支持一句话记录。
- 支持从聊天转成记录。
- 支持后续在桌面端补充细节。

### 3.5 知识库页

知识库页用于查询用户已投喂资料。

页面模块：

- 搜索框。
- 项目筛选。
- 标签筛选。
- 最近查询。
- 查询结果列表。
- 来源引用。

查询结果应包含：

- 标题或摘要。
- 来源文件。
- 页码、章节或幻灯片编号。
- 相关度提示。
- “用它问 Roxy”入口。

手机版知识库不建议初期提供：

- 大批量上传。
- 复杂重建索引。
- 高级知识图谱。
- 复杂文件权限管理。

这些更适合桌面端完成。

### 3.6 设置页

设置页用于手机端基础控制。

页面模块：

- 用户档案。
- 同步状态。
- 隐私设置。
- 语音设置。
- 通知设置。
- 数据管理。

重要设置：

- 是否允许手机端写入长期记忆。
- 是否允许手机端记录收入。
- 是否允许手机端记录健康和心情。
- 是否开启语音输入。
- 是否接收提醒。

## 4. 导航结构

### 4.1 底部导航

手机端推荐使用底部导航。

底部导航项：

- 首页
- 聊天
- 计划
- 记录
- 知识库

原因：

- 单手操作友好。
- 功能入口清楚。
- 符合手机浏览器访问习惯。

### 4.2 一级导航

```text
首页
聊天
今日计划
成长记录
知识库
设置
```

其中设置可以放在首页右上角或个人入口，不一定占用底部导航。

### 4.3 二级导航

今日计划二级结构：

- 全部
- 学习
- 项目
- 健康
- 赚钱

成长记录二级结构：

- 今日
- 本周
- 本月
- 学习
- 项目
- 健身
- 收入
- 心情

知识库二级结构：

- 搜索
- 最近
- 项目
- 标签
- 文件

### 4.4 快捷入口

手机版应提供快捷入口：

- 首页快速聊天。
- 首页快速记录。
- 聊天页快捷指令。
- 计划页一键完成。
- 记录页一句话记录。
- 知识库页快速提问。

### 4.5 导航原则

- 不超过五个底部导航项。
- 设置不占核心导航位。
- 记录入口必须容易找到。
- 计划和记录要区分：计划是未来行动，记录是已经发生。
- 知识库查询不要藏在聊天里，必须有独立入口。

## 5. 数据同步方案

### 5.1 同步目标

手机版和桌面端应共享同一个 Roxy。

同步内容：

- 聊天记录。
- 今日计划。
- 成长记录。
- 长期记忆。
- 知识库索引。
- 用户设置。

同步目标不是所有内容实时强一致，而是让用户在两端看到一致的成长状态。

### 5.2 数据分类

建议按数据敏感度和实时性分类。

高实时性：

- 今日计划。
- 聊天消息。
- 快速成长记录。

中实时性：

- 周报。
- 月报。
- 项目进度。
- 学习记录。

低实时性：

- 知识库索引。
- 文档解析结果。
- 长期成长统计。

高敏感性：

- 收入记录。
- 健康记录。
- 心情记录。
- 长期记忆。

### 5.3 同步模式

推荐采用“本地优先 + 云端同步”的设计方向。

桌面端：

- 保留完整本地数据。
- 负责重型任务，例如文件投喂、解析和知识库维护。
- 可以作为主要数据源。

手机端：

- 通过浏览器访问。
- 读取同步后的轻量数据。
- 写入聊天、计划和成长记录。
- 查询知识库索引和摘要。

云端或同步服务：

- 负责跨端数据同步。
- 负责账号或设备绑定。
- 负责冲突处理。
- 负责访问权限控制。

### 5.4 同步流程

手机端读取流程：

1. 用户打开手机浏览器。
2. 系统验证用户身份。
3. 拉取今日计划、最近聊天、成长摘要和知识库索引。
4. 页面展示当前同步状态。

手机端写入流程：

1. 用户在手机端新增记录或发送消息。
2. 数据写入同步服务。
3. 同步服务标记版本号和更新时间。
4. 桌面端下次在线时拉取更新。
5. 如果发生冲突，按规则合并或提示用户。

桌面端写入流程：

1. 桌面端新增聊天、记忆、知识或成长记录。
2. 本地保存。
3. 如果开启同步，将变更发送到同步服务。
4. 手机端刷新或重新进入时获取最新数据。

### 5.5 冲突处理

可能冲突：

- 手机端和桌面端同时编辑同一条计划。
- 两端同时修改同一条记忆。
- 用户在一端删除记录，另一端还在编辑。

建议规则：

- 聊天记录按时间追加，不合并内容。
- 今日计划按任务 ID 合并状态。
- 成长记录如果冲突，保留两个版本并提示用户。
- 长期记忆冲突必须用户确认。
- 删除操作优先级高，但应保留短期恢复能力。

### 5.6 同步状态展示

手机端应展示同步状态：

- 已同步。
- 正在同步。
- 离线。
- 有冲突。
- 同步失败。

用户应该知道：

- 当前数据是否已保存。
- 手机端记录是否已同步到桌面端。
- 是否有内容等待处理。

### 5.7 离线策略

手机浏览器可以支持有限离线能力。

离线可做：

- 查看最近计划。
- 查看最近成长记录。
- 写入临时记录。
- 草稿保存。

离线不建议做：

- 查询完整知识库。
- 上传大型文件。
- 复杂记忆编辑。

离线恢复后：

- 自动尝试同步。
- 显示待同步记录。
- 冲突时请求用户选择。

### 5.8 隐私和权限

手机版涉及更多隐私风险，因为手机更容易被他人看到。

建议：

- 收入记录默认隐藏金额。
- 心情记录默认私密。
- 健康记录默认谨慎展示。
- 长期记忆编辑需要二次确认。
- 知识库敏感文件可设置为桌面端可见，不在手机端展示。
- 手机端会话可设置自动锁定。

## 6. 版本建议

### 6.1 手机版 MVP

目标：验证手机浏览器访问是否能帮助用户保持成长记录。

包含：

- 首页。
- 聊天。
- 今日计划。
- 一句话成长记录。
- 基础同步状态。

不包含：

- 完整知识库。
- 复杂记录报表。
- 文件上传。
- 高级离线。

### 6.2 手机版 V1

目标：形成可用的移动成长入口。

包含：

- 完整底部导航。
- 聊天页。
- 今日计划页。
- 成长记录页。
- 知识库查询基础版。
- 设置页。
- 同步状态展示。

### 6.3 手机版 V2

目标：增强跨端成长管理。

包含：

- 周报查看。
- 月报查看。
- 更完整知识库查询。
- 移动端语音输入。
- 离线草稿。
- 冲突提示。

### 6.4 手机版 V3

目标：接近完整跨端陪伴。

包含：

- 移动端资料投喂。
- 高级知识筛选。
- 多设备同步优化。
- 隐私锁。
- 手机端提醒。
- 毕业阶段成长回顾。

## 7. 与桌面端的关系

桌面端是主阵地：

- 桌宠常驻。
- 深度聊天。
- 文件投喂。
- 知识库管理。
- 复杂成长复盘。

手机端是随身入口：

- 快速聊天。
- 今日计划。
- 快速记录。
- 知识查询。
- 简单复盘。

两端应该共享：

- 同一个 Roxy 人格。
- 同一份长期记忆。
- 同一个成长阶段。
- 同一套项目和目标。

## 总结

RoxyPlan 手机版应优先做成手机浏览器可访问的轻量成长入口。

它的核心不是复制桌宠，也不是做移动聊天机器人，而是让用户随时能继续推进学习、健康、项目、赚钱和长期成长。

推荐优先级：

1. 首页和聊天。
2. 今日计划。
3. 成长记录。
4. 知识库查询。
5. 数据同步。

当桌面端承担深度工作，手机端承担随身记录，RoxyPlan 才能真正从桌面陪伴扩展为长期成长系统。

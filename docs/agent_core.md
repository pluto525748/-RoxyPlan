# RoxyPlan Agent Core

## 当前定位

V1.6 的 Agent Core 是现有本地功能的受限协调层。它可以理解目标、选择已注册内部工具、执行最多三个步骤，并根据真实工具结果回复用户。它不是通用电脑 Agent，也没有自由探索或无限循环能力。

调用链为：用户输入 → 固定命令/本地语义/可选 LLM 结构化意图 → `AgentCore` → `AgentPlanner` → `SafetyPolicy` → `ToolExecutor` → 现有 Manager 或桌宠动作接口 → `ToolResult` 后置校验 → 确定性事实回复。

## 组件职责

- `ToolRegistry`：声明工具名称、参数、风险、确认要求和处理器。处理器只调用已有 Manager 或动作接口。
- `AgentPlanner`：把结构化意图转换为一到三个白名单步骤。默认使用本地规则。
- `SafetyPolicy`：独立判断风险、置信度、否定表达、询问表达和确认状态。
- `ConfirmationManager`：按会话在运行时保存短时确认，绑定工具名和参数，取消、过期或执行后立即失效。
- `ToolExecutor`：拒绝未知、禁用、参数不合法或未确认的工具，并捕获处理器异常。
- `AgentCore`：按顺序执行步骤，前一步失败时停止依赖步骤，并只根据 `ToolResult` 汇报结果。
- `ConversationStateManager`：保存当前会话的最近任务指代、明确当前事实和敏感话题抑制；这些状态不会自动写入长期记忆。

## 意图、澄清与执行

固定命令优先。本地规则使用句式、实体、同义表达和最近结构化目标处理常见请求；规则无法确认时，可选模型层只能返回白名单 `IntentResult` JSON。非法意图、额外实体、低置信度和解析失败不会执行工具。

- 明确、完整的低/中风险操作可以直接执行。
- “想做”“可能做”等愿望与真正写入请求分开，必要时先询问是否加入计划或记录。
- 缺少目标或字段时只询问缺失内容。
- 多个相近目标只展示候选，不猜测执行。
- 普通消息会取消上一条未确认操作，之后的“确认”不能执行过期参数。

桌面端启用模型意图辅助时，该解析与普通模型回复都在现有 QThread Worker 中完成；Web 端同步调用同一个 `ConversationService`。

## 风险边界

低风险查看、复盘生成、舞蹈和唤醒可直接执行。添加计划、完成计划、行动记录、复盘保存、明确记忆请求、提醒控制和睡眠属于中风险，需要达到配置的置信度。删除计划、删除记忆、归档记忆、恢复记忆以及清空类操作属于高风险，始终要求二次确认。

“不要删除记忆1”不会执行删除；“怎么删除记忆”只是询问，也不会执行。确认默认在三分钟后过期，且只能确认当时绑定的工具与参数。

`ToolResult` 包含 `success`、`status`、`message_code`、`display_message`、`data` 和安全错误对象。添加、更新、完成、删除和记录等关键操作还会验证持久化后的数据形状或状态；`success=false` 时回复不得声称已经完成。

## 内部工具与外部工具

当前工具只覆盖 RoxyPlan 已有的计划、行动记录、成长复盘、长期记忆、主动提醒和桌宠动作。工具没有直接 JSON 写入权，数据仍由原有 Manager 管理。

当前明确不支持：

- Shell、CMD 或 PowerShell 命令。
- 任意 Python 代码执行。
- 任意文件读取、写入、移动或删除。
- 任意桌面点击、键盘控制或应用控制。
- 自主联网搜索、账号操作或无限自主循环。

## 模型辅助与降级

LLM Intent Parser 和 LLM Planner 默认关闭。开启后，模型只能输出受限 JSON；Intent Parser 不能选择枚举外意图，Planner 只能从已启用工具白名单中规划最多三个步骤。未知工具、额外参数、非法格式或低置信度都会回退普通聊天或澄清。模型不能直接调用 Manager，也不能宣称未发生的操作成功。

后续若扩展日历、通知、文件或网页工具，应为每项能力单独定义参数、最小权限、风险等级、确认规则和自动化测试，不能通过通用 Shell 或任意文件接口绕过边界。

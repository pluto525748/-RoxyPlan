# RoxyPlan V1.6 手动验收清单

本清单用于桌面端和 Local Web 的真实体验验收。测试前建议备份本地私人数据；不要使用重要计划执行删除测试。

## 1. 启动与基础聊天

1. 启动桌面端，确认欢迎语自然且能恢复最近会话。
2. 发送普通聊天，确认 thinking 动画持续到回复完成，窗口没有冻结。
3. Ollama 未启动时，确认普通聊天返回友好错误，但“查看计划”“你记得我什么”等本地工具仍可用。

## 2. 意图、澄清与确认

依次尝试：

```text
我今天下午想学一会儿
今天抽点时间学机器学习
换个话题吧
确认
```

预期：第一句询问具体内容；第二句展示准确确认摘要；第三句打断确认；第四句说明当前没有等待确认，不会添加计划。

再发送：

```text
今天抽点时间学机器学习
确认
查看计划
```

预期：确认前无数据变化，确认后计划真实出现。

开放表达与跨主题测试：

```text
你认识我吗
我要学习唱歌
唱完了，给我下午安排学习任务
我下午要安排3个小时的机器学习时间
我们聊聊唱歌练习
把你说的这条加入长期记忆
这个模型相当于人类几岁的智力
```

预期：第一句确定性展示正式长期记忆；新兴趣和缺少具体主题的安排先澄清，不凭旧话题猜任务；明确的三小时机器学习安排写入下午计划并解析时长；引用上一条建议时只创建待审核记忆候选，临时安排会提示更适合放入今日计划；最后的问题直接回答概念，不强行附加编程练习、健康建议或“五分钟任务”。

## 3. 计划生命周期

```text
今日计划：学习机器学习30分钟
刚才那个改成50分钟
推迟到晚上
这件事做完了
刚才那个改成60分钟
重新打开这个
刚才那个改成60分钟
算了，不做这个了
确认
```

预期：同一计划依次更新时长和时间、完成；已完成时拒绝修改核心字段；重开后可修改；取消需要确认并保留取消状态。

相似计划测试：

```text
今日计划：学习线性代数30分钟
今日计划：学习线性代数50分钟
```

预期：第二条不会静默添加，回复提供更新原计划、`仍然添加：...` 或取消的选择。

## 4. 行动、复盘与成长日志

上午完成并保存一次复盘，下午再添加并完成计划：

```text
记录：上午完成了阅读
今日复盘
保存今日复盘
今日计划：下午整理文档
完成计划1
记录：下午整理了文档
今日复盘
保存今日复盘
查看成长日志
```

预期：第二次复盘反映全天最新内容；同一天成长日志更新同一条记录，不重复生成无意义条目。

## 5. 记忆相关性与抑制

在已有健康记忆的前提下依次发送：

```text
晚上吃什么
哈哈
我要睡觉了
你这个回答太笨了
不要再提肠胃了
聊聊机器学习
胃不舒服吃什么
```

预期：第一句和最后一句可以使用健康记忆；中间闲聊、睡觉、负面表达和学习问题不应反复提肠胃；抑制不会删除长期记忆。

## 6. 时空状态

准备三类正式记忆：籍贯洛阳、当前在沈阳、未来想去洛邑古城。测试：

```text
我周末附近有什么地方可以逛？
我回老家有什么地方能玩？
以后去洛邑古城怎么玩？
我现在已经回洛阳了
周末附近去哪？
```

预期：依次优先沈阳、洛阳稳定身份、未来意向；明确回洛阳后，本轮立即使用洛阳，同时只生成待审核状态候选，不静默覆盖正式记忆。

## 7. 删除与危险操作

```text
删除所有记忆
取消
```

预期：对象必须是长期记忆而不是计划，摘要显示数量、范围和不可逆性；取消后数据不变。真实批量删除仅建议在临时测试数据中验证。

## 8. 会话与知识库

1. 新建两个会话并分别聊天，切换后确认内容不串线。
2. 发送“你记得刚才说什么”，确认返回当前会话最近内容。
3. 发送“你记得以前聊过什么”，确认返回本地会话列表而不是让模型猜测。
4. 在 `data/knowledge/` 放入 UTF-8 `.txt` 或 `.md`，相关问题应引用有限片段，无关问题不注入全文。
5. 空目录或损坏文件不能拖垮普通聊天，控制台只记录受控警告。

## 当前边界

- 可选 LLM 意图辅助提高开放表达覆盖，但仍可能请求澄清。
- 等待确认按会话保存在当前进程，重启后失效。
- 当前使用本地 JSON 与轻量锁，不是数据库事务系统。
- 正式长期记忆仍必须经过候选审核；计划、行动、摘要和模型推断不会自动进入长期记忆。

# Frontend

This directory contains the RoxyPlan desktop pet frontend prototype.

## Current Version

V0.2 implements the smallest interactive desktop pet chat prototype:

- Desktop pet window
- Default avatar drawing
- Drag support
- Always-on-top window
- Double-click to open a chat window
- Chat record display area
- Text input box
- Send button
- Enter key sending
- Automatic scroll to bottom
- Timestamp display
- Fixed local Roxy reply

## Not Included

- No AI integration
- No database integration
- No voice integration
- No knowledge base integration
